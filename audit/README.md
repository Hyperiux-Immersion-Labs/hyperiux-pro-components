## 🚨 Executive Finding: The 3 Core Registry Vulnerabilities

Our rigorous audit has identified three systematic, library-wide architectural vulnerabilities that currently impact production readiness and the developer experience:

### 1. The NPM Empty-Tarball Epidemic (Critical — Category-wide)
> [!CRITICAL]
> Across multiple core interactive categories (including `buttons`, `carousels`, `loaders`, `navigation`, and `transitions`), the `package.json` configurations are broken. The `main` and `files` keys refer to non-existent filenames based on old draft structures (e.g. `rotating-carousel.jsx`, `lines-loader.jsx` etc.) instead of `index.jsx` or the actual source files.
> Consequently, running `npm pack` compiles **entirely empty tarballs** that contain only `package.json` and `registry.json`—entirely omitting the executable React components from the distributed packages in `registry/dist/`.

### 2. Missing Files in Registry Declarations
> [!IMPORTANT]
> Multiple premium components (such as `horizontal-feature-reveal` and `hyperiux-glitter`) list vital source files or 3D GLB assets in their `registry.json` descriptors that are **completely missing** from the local file system. This causes local registry pack scripts to fail or crash.

### 3. Outdated Manifest and Dependency Drift
> [!WARNING]
> Extensive file drift exists between the distributed source code in `registry/` and the documentation site templates under `apps/docs/src/components/`. For example, `fractal-glass` has a completely stale public json manifest that runs un-gated render loops, and several components bypass standard `index.jsx` entry points entirely inside documentation layout pages.

---

## 🗺️ Recommended Remediation Roadmap

1. **Unified Entry Point Transition (Priority 0):** Systematically update all `package.json` configurations across all categories to target `index.jsx` as `"main"`, ensuring `"files"` correctly captures all co-located JS/JSX/CSS. This will instantly solve the empty tarball epidemic.
2. **Local Asset Reconciliation (Priority 0):** Restore missing local assets (like `hyperiux-new-model.glb` for `hyperiux-glitter`) or decouple them from local manifests in favor of verified CDN resources.
3. **Context-Safe GSAP Cleanup Integration (Priority 1):** Systematically replace dangerous global teardown side-effects (like `ScrollTrigger.getAll().forEach(t => t.kill())`) with localized GSAP context reverts (`ctx.revert()`).
4. **Intersection Observer Rollout (Priority 1):** Mandate the usage of `createSuspendedRaf` or standard IntersectionObservers to pause high-frequency canvas loops when scrolled off-screen or inside background tabs.
5. **Standardized A11y Reduced-Motion Integration (Priority 2):** Create a unified system hook checking `prefers-reduced-motion` to automatically freeze heavy typography transitions and WebGL swarms.
