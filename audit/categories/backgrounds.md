# backgrounds — Category Report

## Category overview

The `backgrounds` category covers full-viewport, decorative-first background effects in the Hyperiux Vault registry: `registry/effects/backgrounds/{dither-canvas,dotted-grid,spider-particles}`. Three effects total, spanning three distinct rendering approaches — WebGL2 custom shader ([dither-canvas](../effects/backgrounds/dither-canvas.md)), Canvas2D ([dotted-grid](../effects/backgrounds/dotted-grid.md)), and Three.js/`THREE.Points` ([spider-particles](../effects/backgrounds/spider-particles.md)) — but all three share the same continuous-rAF-driven-animation shape, the same F-042 visibility-suspension requirement, and the same two-copy (registry + docs-site) distribution model. This report synthesizes the three individual audits; no new code was read or re-derived here beyond what those reports already cite.

## Common patterns across its effects

- **All three correctly implement the F-042 `createSuspendedRaf` rAF-suspension pattern in their registry source.** `dither-canvas` ([index.jsx#L711-L713](../../registry/effects/backgrounds/dither-canvas/index.jsx#L711-L713)), `dotted-grid` ([index.jsx#L285-L365](../../registry/effects/backgrounds/dotted-grid/index.jsx#L285-L365)), and `spider-particles` ([index.jsx#L297-L299](../../registry/effects/backgrounds/spider-particles/index.jsx#L297-L299)) all pass a `root` element into a locally-copied `createSuspendedRaf.js` and call `loop.destroy()` on unmount, matching the "copy, don't import" rollout convention documented in `registry/effects/_shared/README.md` and confirmed done for exactly this trio ("Task 3 (backgrounds): dither-canvas, spider-particles, dotted-grid — done").
- **All three have thorough, symmetric unmount cleanup.** Every listener added is removed by name, and all GPU/DOM resources are explicitly torn down: `dither-canvas` deletes GL textures/buffer/program individually ([index.jsx#L817-L834](../../registry/effects/backgrounds/dither-canvas/index.jsx#L817-L834)); `dotted-grid` removes all four listeners and calls `loop.destroy()` ([index.jsx#L376-L382](../../registry/effects/backgrounds/dotted-grid/index.jsx#L376-L382)); `spider-particles` disposes the renderer plus every geometry/material and removes five mount-level listeners ([index.jsx#L381-L401](../../registry/effects/backgrounds/spider-particles/index.jsx#L381-L401)).
- **All three ship a broken npm tarball with the identical root cause.** Every `package.json` in this category declares `"main": "{slug}.jsx"` and lists that nonexistent file in `"files"`, instead of the actual entry point `index.jsx` (and, for `dither-canvas`/`spider-particles`, also omits `createSuspendedRaf.js`). This was independently confirmed for all three by inspecting the built artifacts directly: `registry/dist/hyperiux-dither-canvas-0.0.1.tgz`, `registry/dist/hyperiux-dotted-grid-0.0.1.tgz`, and `registry/dist/hyperiux-spider-particles-0.0.1.tgz` each contain only `package/package.json` and `package/registry.json` — zero component code in any of them.
- **All three have a stale `public/r/*.json` CLI mirror relative to current registry source**, in every case because `npm run build:registry` was not re-run after the F-042 refactor landed: `apps/docs/public/r/dither-canvas.json`, `apps/docs/public/r/dotted-grid.json`, and `apps/docs/public/r/spider-particles.json` all predate the `createSuspendedRaf` adoption in their respective registry `index.jsx` files.
- **All three have a demo page that renders a docs-site copy which has visibly drifted from the registry copy** — in every case the drift is a breakpoint/class mismatch (and for `dotted-grid`, a missing animation phase and a missing UI hint), meaning the public preview does not accurately represent what a CLI install actually produces.
- **None of the three implement `prefers-reduced-motion`.** Confirmed absent via grep across all three components and their shared rAF helper.
- **None of the three components or their `package.json` declare `peerDependencies`** for `react` (and, for `spider-particles`, `three`) — noted explicitly in the `spider-particles` report and structurally present in all three.
- **All three keep per-frame animation state in refs/closures, not `useState`**, avoiding unnecessary React re-renders during animation — a consistently-followed good pattern.

## Repeated issues (grouped by severity)

### Critical

- **Packed npm tarball ships zero component code, in all three effects.** Root cause is identical: `package.json`'s `main`/`files` reference a nonexistent `{slug}.jsx` instead of `index.jsx`.
  - `dither-canvas`: [package.json](../../registry/effects/backgrounds/dither-canvas/package.json), confirmed via `tar -tzf registry/dist/hyperiux-dither-canvas-0.0.1.tgz`.
  - `dotted-grid`: [package.json#L5-L9](../../registry/effects/backgrounds/dotted-grid/package.json#L5-L9), confirmed via `tar -tzf registry/dist/hyperiux-dotted-grid-0.0.1.tgz`.
  - `spider-particles`: [package.json#L5-L9](../../registry/effects/backgrounds/spider-particles/package.json#L5-L9), confirmed via `tar -tzf registry/dist/hyperiux-spider-particles-0.0.1.tgz`.
  - This is the dominant driver of every Critical severity label in this category. The `dither-canvas` audit notes the actual production blast radius of the `registry/dist` tarball pipeline specifically is unconfirmed (no script found that consumes it downstream of `vault.hyperiux.com/r`), but flags it as broken functionality per the rubric regardless, since the artifact is genuinely non-functional as built.

### High

- **Stale `public/r/*.json` mirror actually reaches real installers for the two free-tier effects.** `dotted-grid` and `spider-particles` are both `tier: "free"`, meaning `public/r/*.json` embeds full source content that CLI installs pull directly — and that embedded content is the pre-F-042 version with a raw, unsuspended `requestAnimationFrame`/`cancelAnimationFrame` loop:
  - `dotted-grid`: [apps/docs/public/r/dotted-grid.json#L18](../../apps/docs/public/r/dotted-grid.json#L18) vs. current source at [registry/effects/backgrounds/dotted-grid/index.jsx#L285-L374](../../registry/effects/backgrounds/dotted-grid/index.jsx#L285-L374).
  - `spider-particles`: [apps/docs/public/r/spider-particles.json#L15-L21](../../apps/docs/public/r/spider-particles.json#L15-L21) vs. current source at [registry/effects/backgrounds/spider-particles/index.jsx#L297-L377](../../registry/effects/backgrounds/spider-particles/index.jsx#L297-L377).
  - This means the documented-complete F-042 rollout is not actually reaching the majority of real installs for 2 of the 3 effects in this category — a live, ongoing CPU/GPU/battery regression for anyone who installs via the public CLI JSON.
  - By contrast, `dither-canvas` is `tier: "pro"`; its public mirror is stale too, but pro-tier installs resolve content from the private `registry.json` + live disk read rather than the public mirror ([apps/docs/src/lib/registry.js#L133-L219](../../apps/docs/src/lib/registry.js#L133-L219)), so that specific instance was downgraded to Medium in its own report — the mechanism (stale mirror) is category-wide, but the blast radius differs by tier.

### Medium

- **Demo-vs-registry drift, all three effects** — the live preview under `/demo/{slug}` renders `apps/docs/src/components/{slug}/index.jsx`, not the registry copy CLI installs actually deliver, and all three have measurably diverged:
  - `dither-canvas`: cursor-hint pill and mobile-fallback breakpoints differ (`max-[1025px]:hidden` vs `max-md:hidden`, etc.) — see [dither-canvas.md §3](../effects/backgrounds/dither-canvas.md).
  - `dotted-grid`: docs copy is missing the `GRAY_DISPERSE_TIME` animation phase entirely and is missing the "Click anywhere to change the pattern" hint that the registry copy lacks — see [dotted-grid.md §3](../effects/backgrounds/dotted-grid.md).
  - `spider-particles`: header/stats-overlay and "Open on desktop" breakpoint differs (`max-md:hidden` in docs copy vs `max-[1025px]:hidden` in registry) — see [spider-particles.md §5](../effects/backgrounds/spider-particles.md).
- **`prefers-reduced-motion` unhandled, all three effects** — flagged as Medium in each individual report per the rubric ("missing prefers-reduced-motion handling"): [dither-canvas.md §4](../effects/backgrounds/dither-canvas.md), [dotted-grid.md, Accessibility assessment](../effects/backgrounds/dotted-grid.md), [spider-particles.md §4](../effects/backgrounds/spider-particles.md).
- **Missing `className` prop / hardcoded colors, contra `developer-new-component.md` Step 1** — `dotted-grid` has no props at all (`DottedGrid()` at [index.jsx#L125](../../registry/effects/backgrounds/dotted-grid/index.jsx#L125)), hardcoding fill/trail colors; `spider-particles` exposes color props but has no `className` prop ([index.jsx#L71-L82](../../registry/effects/backgrounds/spider-particles/index.jsx#L71-L82)). `dither-canvas` hardcodes shader glyph tint and overlay colors with no props ([index.jsx#L189](../../registry/effects/backgrounds/dither-canvas/index.jsx#L189), [#L850-L860](../../registry/effects/backgrounds/dither-canvas/index.jsx#L850-L860)). Severity Low-to-Medium depending on effect per each individual report; grouped here as a repeated pattern.

### Low

- **Decorative comment dividers violate `CODING_STANDARDS.md` §1 in all three files** — `dither-canvas` ([index.jsx#L6](../../registry/effects/backgrounds/dither-canvas/index.jsx#L6) and 4 more sites), `dotted-grid` ([index.jsx#L6](../../registry/effects/backgrounds/dotted-grid/index.jsx#L6) and 4 more sites), `spider-particles` (14 sites, e.g. [index.jsx#L7](../../registry/effects/backgrounds/spider-particles/index.jsx#L7)). This is the single most consistent Low-severity finding in the category — every effect's file uses the same disallowed Unicode box-drawing header style.
- **Missing `peerDependencies` in `package.json`** — noted explicitly for `spider-particles` ([package.json#L1-L14](../../registry/effects/backgrounds/spider-particles/package.json#L1-L14)) and flagged there as "same gap exists in `dither-canvas` and `dotted-grid`," i.e. a repo-wide template gap across the whole category, not one component's oversight.

## Best practices to standardize

- **`spider-particles`'s prop design is the category's high-water mark for customization.** It exposes `particleColor`, `webColor`, `glowColor`, and `centerColor` as props with sensible `0xffffff` defaults ([index.jsx#L71-L82](../../registry/effects/backgrounds/spider-particles/index.jsx#L71-L82)) — no hardcoded colors, matching `CODING_STANDARDS.md` exactly. `dither-canvas` and `dotted-grid` should adopt the same pattern instead of hardcoding shader/canvas fill colors.
- **`dither-canvas`'s cleanup is the most exhaustive GL-resource teardown in the category** ([index.jsx#L817-L834](../../registry/effects/backgrounds/dither-canvas/index.jsx#L817-L834)) — it additionally pauses/unloads the `<video>` element and revokes its blob URL, a resource class the other two effects don't have but is a good model for any future video-backed effect.
- **`dotted-grid`'s pure-function shape math** (`getStarStrength`, `getSquareStrength`, etc., all stateless and unit-testable in isolation per [dotted-grid.md](../effects/backgrounds/dotted-grid.md)) is a cleaner separation-of-concerns than the other two effects' more monolithic `useEffect` bodies, and is worth pointing to as the category's best example of isolating pure math from the stateful component shell.
- **All three should be brought to `dither-canvas`'s and `dotted-grid`'s mobile-awareness bar.** `dither-canvas` scales glyph density down on small viewports and disables the cursor-fluid effect by default on mobile with a visible fallback message; `dotted-grid` uses unified `pointermove`/`pointerleave` handling so touch and mouse share one code path. `spider-particles`'s touch listeners are wired up but functionally inert below its `isDesktop()` gate (1025px) — consistent with intent, but the category would benefit from a single documented convention for how "mouse-only" effects communicate their touch/mobile fallback, rather than three different bespoke breakpoints (`639px`/`1025px` for `dither-canvas`, `xl` for `dotted-grid`'s registry copy, `1025px` for `spider-particles`).
- **The `createSuspendedRaf` copy-per-effect convention is working as designed** — all three local copies were verified byte-identical (or structurally identical) to `registry/effects/_shared/createSuspendedRaf.js` across all three reports. This pattern should continue to be the standard for any future backgrounds effect.

## Prioritized list of improvements

Ordered by severity, then by number of effects impacted / install-path blast radius:

1. **(Critical, all 3 effects) Fix the `package.json` `main`/`files` fields** in `dither-canvas`, `dotted-grid`, and `spider-particles` to reference `index.jsx` (+ `createSuspendedRaf.js` where applicable) instead of the nonexistent `{slug}.jsx`, then re-run `npm pack`/`build:registry` to regenerate all three tarballs. All three individual reports independently recommend fixing this once, e.g. by correcting `ensurePackageForEffect` in `apps/docs/scripts/build-registry.js` if that's what generates these files, rather than patching each `package.json` by hand three times.
2. **(High, 2 of 3 effects — the free-tier ones) Re-run `npm run build:registry`** to regenerate `apps/docs/public/r/dotted-grid.json` and `apps/docs/public/r/spider-particles.json` so real CLI installs receive the F-042-suspended render loop instead of the pre-refactor continuous `requestAnimationFrame`. This is the highest-impact fix after item 1, since it's actively shipping a performance regression to real installers today. Regenerating `apps/docs/public/r/dither-canvas.json` too is lower urgency (pro-tier installs bypass the public mirror) but should be done in the same pass for consistency and to avoid the same staleness surfacing if `dither-canvas`'s tier ever changes.
3. **(Medium, all 3 effects) Reconcile each demo page's docs-site copy with its registry copy** — at minimum align the drifted breakpoints/classes, and for `dotted-grid` specifically restore the missing `GRAY_DISPERSE_TIME` phase and the "Click anywhere to change the pattern" hint, so each public demo accurately represents what installing actually produces.
4. **(Medium, all 3 effects) Add `prefers-reduced-motion` handling**, most naturally by extending the shared `createSuspendedRaf`/`createVisibilityGate` mechanism (all three already depend on it) with a `matchMedia("(prefers-reduced-motion: reduce)")` gate, so the fix is written once and copied into all three local copies the same way the visibility-suspension pattern was rolled out.
5. **(Medium, 2 of 3 effects) Add `className` prop support to `dotted-grid` (which has no props at all) and `spider-particles`**, and move hardcoded colors in `dither-canvas` and `dotted-grid` behind props with sensible defaults, matching `spider-particles`'s existing color-prop pattern.
6. **(Low, all 3 effects) Remove decorative comment dividers** to comply with `CODING_STANDARDS.md` §1, and **add `peerDependencies` (`react`, and `three` for `spider-particles`)** to all three `package.json` files — both are mechanical, low-risk, repo-wide template fixes that can be done in one pass across the category.
