# Remixer Effect Prop Inventory

Generated from `registry/effects/**/registry.json` and each effect's public registry entry component. This inventory is for planning Remixer Panel schemas across both free and pro effects.

Notes:

- Tables list props exposed by the installable registry component where they can be detected from destructured component parameters.
- `...props` / `...rest` means native or passthrough props are forwarded; these are usually not direct remixer controls.
- Effects marked with no detected public props may still have internal demo data, but those values are not currently configurable through the installable component API.
- Descriptions are intentionally short and should be refined during each effect-specific remixer migration.
- Sections marked **Suggested props** are planning candidates only. Add these props to the effect's `registry/effects/.../index.jsx` public API before exposing them in copied code or treating them as implemented registry props.
